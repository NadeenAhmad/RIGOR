[What is the total number of unique invoice lines?]

The ontology would count the number of unique entries in the InvoiceLineId column, as InvoiceLineId is the primary key and thus each entry is unique.

---

[Which invoice has the most lines?]

The ontology would group the entries by InvoiceId and count the number of lines for each invoice, then select the InvoiceId with the highest count. This can be done using a GROUP BY and COUNT query.

[What is the total revenue generated by a specific track (TrackId)?]

The ontology would sum the product of UnitPrice and Quantity for the given TrackId. This can be done using a SELECT SUM query with a WHERE clause for the specific TrackId.

---

[How many times has a specific track (TrackId) been purchased?]

The ontology would sum the Quantity for the given TrackId. This can be done using a SELECT SUM query with a WHERE clause for the specific TrackId.

---

[What is the average unit price of all tracks?]

The ontology would calculate the average of the UnitPrice column. This can be done using a SELECT AVG query on the UnitPrice column.
