[What is the unique identifier for each employee in the database?]

The EmployeeId field in the Employee table uniquely identifies each employee, as it is an integer and a primary key.

---

[Which employees report to the employee with ID 2?]

The ontology would filter the records where the ReportsTo field matches the value 2, and then return the FirstName, LastName, Title, and other relevant fields for those employees.

---

[What is the email address of the employee with ID 3?]

The ontology would search for the record where the EmployeeId field is 3, and then return the value in the Email field.

---

[Which employees have the title 'Sales Support Agent'?]

The ontology would filter the records where the Title field is 'Sales Support Agent', and then return the FirstName, LastName, Email, and other relevant fields for those employees.

---

[What is the full address of the employee with last name 'Peacock'?]

The ontology would filter the records where the LastName field is 'Peacock', and then return the values in the Address, City, State, Country, and PostalCode fields to provide the full address.
